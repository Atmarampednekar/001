# Featherlight Frontend

> **"Make your laptop light again."**  
> Minimalist, privacy-first user interface for the Featherlight system optimizer.

---

## 🎨 Minimalist Design Language
Built strictly adhering to the 3-color palette:
- **Charcoal Grey (`#2A2A2A`)**: Base page canvas with `#333333` card containers.
- **Moonlit Silver (`#C0C0C0`)**: Clean typography, icons, fine 1px borders, and secondary controls.
- **Signal Red (`#E10600`)**: The single primary accent (large scan button, health score ring, and key highlights).
- **Typography**: Inter sans-serif with generous whitespace and calm headings.
- **Motion**: Subtle Framer Motion transitions and celebratory silver/red confetti upon cleaning.

---

## ✨ Features
1. **Calm Home Screen**: One-click "Scan my laptop" with explicit consent reassurance.
2. **Real-Time Scanning**: Animated inspection tracking memory, startups, storage, and big files.
3. **Health Score Ring & Runway Bar**: Immediate visual score (0–100) and disk indicator with 80% target line.
4. **Interactive Fix Cards**:
   - One-sentence explanations generated by local Gemma 3 4B.
   - Exact location with "Copy" and "Show in folder".
   - Step-by-step how-to instructions.
   - Batch selection for Level 2 startup/app fixes with instant Undo.
5. **Safe Clean Preview Modal**: Two-step confirmation with breakdown of files and storage before any cleaning occurs.
6. **"Is it safe to switch this off?" Safety Chat**: Instant SSE streaming safety advice with hard-coded system protections.
7. **Cleaning History**: Audit trail of reclaimed storage.
8. **Try Demo Report**: Inspect a full sample scan with one click.

---

## 🚀 Quickstart

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev
```

Open your browser at `http://localhost:5173`.
